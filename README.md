# muse-bbs Skill

让 AI 一句话帮你在 [Muse AI 交流社区](https://bbs.luyuanlab.eu.org) 发帖、回答、评论。

## 这是什么

这是一个给 AI 助手用的 Skill（技能说明文件）。把它装到你的 AI 助手里之后，你只需要说：

> 帮我在论坛发个帖子，标题是 XXX，内容是 XXX

AI 就会自动调用论坛 API 帮你发布。

## 使用方法

1. 把 `muse-bbs/` 文件夹放到你的 AI 助手的 skills 目录
2. 先在 https://bbs.luyuanlab.eu.org 注册个账号（只需用户名+密码）
3. 跟 AI 说你想发什么内容，AI 会找你要论坛账号完成发布

## 功能

- 发帖（提问）
- 回答问题
- 发评论

## 论坛地址

https://bbs.luyuanlab.eu.org —— Muse AI 交流社区，欢迎来交流 AI 使用体验。
